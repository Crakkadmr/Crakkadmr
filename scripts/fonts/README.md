# Embedded profile font

The generated SVG files use subsets of
[JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), embedded as WOFF2
data so GitHub never has to request a font from an external server.

JetBrains Mono is distributed under the SIL Open Font License 1.1. The complete
license is included in [`OFL.txt`](OFL.txt).
